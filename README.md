# Prediccion-Clima-NASA
Proyecto de análisis de datos, construyendo modelos capaces de predecir la temperatura y la precipitación del dia siguiente

* Recolección de datos a través de la API de la página de NASA Power: https://power.larc.nasa.gov/
* Limpieza y exploración de datos
* Construcción de modelo *Random Forest Classifier* para predecir si **lloverá** el dia siguiente o no
* Construcción de modelo *Random Forest Regressor* que predice la **temperatura máxima** del dia siguente
